# Extra examples

This directory contains optional examples that are useful alongside the main
ExMed-BERT project but are not part of its supported AI Runtime workflow.

| Directory | Purpose |
|---|---|
| [llm_sft](llm_sft/README.md) | Generic Qwen supervised fine-tuning and model-serving notebook |

The recommended ExMed-BERT demonstration remains under
[`experiments/ai_runtime_exmedbert`](../experiments/ai_runtime_exmedbert/README.md).

`extra/local/` is ignored and can hold private scratch notes or session handoff
files that should not be committed.
